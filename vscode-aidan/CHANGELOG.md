# Change Log

## [1.0.0] - 2024-01-01

### Added
- Multi-model AI support (OpenAI, Anthropic, OpenRouter)
- Autonomous file operations (create, edit, delete, read)
- Terminal command execution
- Unity MCP integration for game development
- Workspace scanning and context awareness
- Interactive chat interface with model selector
- Action confirmation system for safety
- Keyboard shortcuts (Ctrl+Shift+A to open chat)

### Supported AI Models
- GPT-4o, GPT-4o-mini (OpenAI)
- Claude Sonnet 4.5, Claude Haiku 4.5, Claude Opus 4.1 (Anthropic)
- DeepSeek Chat, Grok 4 (OpenRouter)

### Unity Integration
- Create GameObjects in scene
- Add components to objects
- Generate C# scripts
- Run Unity menu items
